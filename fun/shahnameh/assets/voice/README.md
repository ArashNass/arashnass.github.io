# Narration

Original character voices and recordings are preserved. The additional 13 cinematic readings and all 17 manuscript pages use the same ElevenLabs narrator, **Cave Monster - Deep Terrifying Monster** (`HASaEuIpR5CVuLzDK1E1`), with Eleven v4, stability 50%, similarity 75%, MP3 44.1 kHz / 128 kbps.

`narration-manifest.json` records the exact additional text, file hashes and durations. The seventh closing retains the existing recorded three-panel ending, starting with `end1.mp3`.

Cinematic readings follow the existing narration timing. Manuscript pages are opt-in: Listen starts the current page, Stop ends it, and changing or closing a page stops its reading. Mute and narrator volume settings apply to both. Page navigation does not automatically start another reading.
